# Awoo 系統自動上帝主持與行動鎖定驗收（Step 9.3）

## 預期行為

- 正式模式由系統擔任上帝，不需要真人主持人按「下一句」。每句口白播放完畢後，無需玩家決策的提示會在短暫停頓後自動推進。
- 當前句要求角色行動時，流程會等待該角色提交合法操作或明確選擇不使用技能；完成後自動播放下一句。只打開選擇器或草稿選目標不算完成。
- 首夜若有狼王，狼人互認後會播報「狼王請比讚。」並留出手勢確認時間，再播放狼隊選刀口白。
- 「狼人請閉眼」等收尾提示播完後，系統自動繼續下一個角色；最後「天亮請睜眼」播完後才會結算夜晚。
- 測試模式刻意保留手動「下一句並播放」、重播及手動確認佔位流程，以便檢查控制台。正式模式不顯示這些主持控制。
- 上帝提醒倒數結束不會自動跳過技能或結算本夜。

## 建議人工測試流程

1. 用本機 HTTP 伺服器開啟 `index.html`，例如在專案根目錄執行 `python -m http.server 8000`，再開啟 `http://localhost:8000`。
2. 正式模式不顯示人工主持控制；測試模式才顯示「下一句並播放」。在測試模式開始遊戲後，等待「天黑請閉眼」唸完，再手動推進。
3. 正式模式中，系統會依序播報「狼人現身，請睜眼」、「狼人請相互確認身份」，若本局有狼王，接著播報「狼王請比讚」，最後播報狼隊選刀提示。口白結束前不能操作；選擇有效目標或「確認空刀」後，系統會自行繼續，不需要手動按下一句。測試模式則仍需手動推進。
4. 推進到女巫救藥口白。女巫必須選擇救人或「不救，保留解藥」才能繼續；如果本夜沒有有效狼刀目標，該救藥問題會被跳過。
5. 推進到女巫毒藥口白。選擇目標後仍不可繼續；必須按「確認使用毒藥」或「不使用毒藥」。按取消或只選一個座位不能解鎖下一句。
6. 推進到預言家、守衛。預言家需要選擇一名有效查驗目標，守衛需要選擇一個合法守護目標，才可繼續。守衛不可連續兩晚守同一人時，該目標應停用。
7. 如果出現尚未實作專屬技能的特殊角色，測試模式會顯示手動流程確認提示；切換到對應存活座位並確認後才解鎖。此操作只確認流程，不能視為技能已實作。
8. 正式模式讓流程自動播放到「天亮請睜眼」，確認此前所有行動都完成後才進入夜晚結算。測試模式需手動推進。檢查死亡名單與天亮公告是否一致。

## 限制與注意

- 此版本目前仍是本機原型，正式模式的上帝口白與回合流程會自動推進，但跨瀏覽器多人房間／伺服器身分驗證尚未實作；在真正多人版本完成前，這不代表不同玩家裝置已能彼此同步操作。視角切換僅供測試。
- 本地語音合成依瀏覽器、作業系統及語音包而異。如果瀏覽器不支援 `speechSynthesis`，程式會依文字提示和角色行動狀態自動推進；若語音合成發生錯誤，系統仍會遵循同一套自動狀態機，不會要求正式模式的真人主持人接手。
- 特殊角色若只有佔位流程，正式模式不會允許直接略過該行動；這是刻意避免尚未實作的技能被當成已完成。測試模式的手動確認只供巡檢流程。
- 測試模式的「立即天亮結算本夜」會刻意繞過主持閘門，請不要在驗證逐句鎖定時按它。
