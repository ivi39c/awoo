# Awoo 上帝夜間口白與角色流程

## 設計原則

`js/moderator-script.js` 會依開局實際出現的角色及當前夜數產生主持流程。沒有配置的角色不會被呼叫；首夜角色（盜賊、邱比特、野孩子、混血兒等）只在首夜加入。流程面板逐句顯示口白，並可透過瀏覽器的繁體中文語音合成朗讀。

- 預設 `awoo-custom` 順序依 Awoo 使用者指定：狼人 → 女巫 → 預言家 → 守衛。
- `classic` 提供另一常見流程：守衛 → 狼人 → 女巫 → 預言家。
- 夜間順序並沒有適用於所有平台的唯一標準；官方活動、桌遊店與不同板型也會不同。開局應固定採用哪個房規，不能在同一局中任意混用。
- 女巫的刀口編號、預言家的查驗結果、守墓人的資訊等私密訊息不應透過公開語音播出。流程說明會提醒主持人改在角色控制台或以約定手勢私下傳達。
- 每個角色的 `ROLE_SCRIPTS` 是已整理的專屬口白模板；若資料庫中有夜間技能但尚無正式模板，建構器會加上通用佔位口白並在「需核對的角色流程」列出，這只代表主持流程有提示，不代表技能已實作。
- 同名角色有多種版本時，口白只提供流程框架；該角色具體技能效果、可選目標、行動次數與結算優先序必須由所選 ruleset 定義。


## 逐句主持與角色行動鎖定（Step 9.2）

上帝流程不是單純把整串台詞唸完，而是「唸完當句 → 等待對應角色完成操作 → 才可進下一句」：

1. 每一個有語音的步驟，必須等瀏覽器語音合成的 `onend`（或播放失敗的 `onerror` fallback）才會解鎖操作與下一句。沒有可用的語音合成時，程式會退回可手動推進的狀態。
2. 狼人襲擊、女巫解藥決策、女巫毒藥決策、預言家查驗、守衛守護等操作口白會有 `actionKey`。只有當對應操作成功記錄，或該角色明確選擇不使用技能時，才會解鎖下一句。
3. 狼人可選擇有效夜刀目標或明確確認空刀；女巫可以確認使用或明確選擇不使用解藥／毒藥。開啟目標清單、點選尚未確認的毒藥目標、或取消選取都不算完成操作。
4. 對尚未實作的特殊角色，通用佔位步驟以 `manual:<角色名>` 標記。只有測試模式會提供主持人手動確認按鈕，且需切換到對應的存活角色座位；此確認只代表檢查過主持流程，不代表該角色技能已可玩。正式模式不會允許略過未實作的主動技能，避免錯誤地將佔位流程當成完成技能。
5. 每夜主持流程只會呼叫仍存活的角色。獵人在常見基礎房規中屬於出局觸發技能，不應每晚被叫醒；但獵人死亡後的開槍流程仍待遊戲引擎完整實作。
6. 夜間提醒倒數不會自動跳過口白或未完成的技能。最後一句「天亮請睜眼」已播放且通過流程閘門後，才會執行夜晚結算。測試模式的「立即天亮結算本夜」是明確的測試捷徑，不代表正式主持可跳過操作。

## 基礎口白

### 全體

1. 「天黑請閉眼。」
2. 依本局角色清單逐組呼叫夜間角色。
3. 「天亮請睜眼。」
4. 天亮公告必須依夜晚結算器回傳的實際死亡清單，不可直接把狼人夜刀目標當成死亡者。

### 狼人

- 「狼人現身，請睜眼。」
- 首夜：「狼人請相互確認身份。」
- 「狼人請選擇今晚要殺的對象，請統一意見。」
- 「狼人請閉眼。」

小女孩、特殊狼或狼同盟是否參與狼人互認／夜刀，依採用板型說明；不應為了有口白而擅自將所有狼角色視為相同技能。

### 女巫

- 「女巫請睜眼。」
- 若解藥仍可用且當夜有有效狼刀：「今天晚上這位玩家死了，你要救他嗎？」主持人只向女巫私下顯示刀口座號。
- 若毒藥仍可用：「你有一瓶毒藥，你要毒死誰嗎？請選擇目標。」女巫控制台顯示所有玩家座位；已出局玩家反灰且禁用。
- 「女巫請閉眼。」

毒藥選擇流程是「點選目標 → 確認使用 → 把目標 ID 儲存到 `roomState.witchPoisonTargetId` → 天亮時交由 `settleNightActions()` 結算」。單純點選或取消不會消耗藥劑；已確認使用才會扣掉一次使用機會。目標在結算前死亡時，結算器會將其視為無效目標並保留警告。

### 預言家

- 「預言家請睜眼。」
- 「今天晚上你要驗誰？」
- 「這個人的身份是……」
- 「預言家請閉眼。」

「好人／狼人」的回覆必須在私密控制台或以約定手勢呈現，避免全場聽到查驗結果。

### 守衛

- 「守衛請睜眼。」
- 「守衛今天晚上你要守護誰？」
- 「守衛請閉眼。」

是否能自守、能否連守、同守同救是否死亡及保護可抵擋哪種傷害，是房規設定，不應寫死在主持詞裡。

目前包含盜賊、邱比特／情侶、混血兒、野孩子、暗戀者、魔術師、狼美人、噩夢之影、石像鬼、機械狼、狼預言家、狼巫、覺醒女巫、純白之女、鍊金魔女、攝夢人、烏鴉、禁言長老、守墓人、獵魔人、子狐、狐狸、奇蹟商人、獵人、吹笛者、縱火狂、吸血鬼、殺人狂、邪教首領、寄生蟲、催眠師、刺客、觀察者、失眠者、通靈師、賞金獵人、潛行者、毒師、守護天使、醫師、偵探、調查員、神諭者、白晝學者等。

## 系統自動主持（Step 9.3）

正式模式下，口白播放完畢後，沒有待辦行動的主持提示會自動推進；角色行動步驟則等待對應角色提交有效選擇。完成後系統自動播放下一句，無需真人主持人點擊。測試模式仍保留手動逐句檢查。

首夜若角色配置含「狼王」，狼人相互確認身份後會新增「狼王請比讚。」提示，留出手勢辨識時間，再播放狼隊選刀口白。
