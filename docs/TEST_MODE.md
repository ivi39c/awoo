# Awoo 測試模式操作指南

## 進入測試模式

1. 開啟 `index.html`。
2. 在大廳選擇 **「測試模式（Bot 填滿・全角色控制台巡檢）」**。
3. 系統會在本機建立 12 個座位，其他座位由 Bot 名稱佔位。這是單機測試環境，不會連接其他瀏覽器或遠端伺服器。
4. 在控制台點擊 **「開始遊戲流程（抽卡發牌）」**。

## 切換視角與檢查角色

- 只有測試模式會顯示頂部的玩家視角下拉選單。
- 開局發牌後，打開右下角控制台的 **「測試模式工具」**，可以把目前選中的座位替換為角色圖鑑中的任意角色。
- 角色覆蓋會讓該座位恢復存活、清除死亡原因和本夜待處理行動；它只修改本機測試局，可能改變陣營人數或勝負條件。
- 頂部顯示「角色控制台巡檢：X / N」。X 是目前在控制台中實際檢視過的不同角色數量，N 由角色資料庫自動讀取。
- 每個角色的「控制項狀態」會提示目前已有的控制項，或指出該角色的專屬技能仍待接入。圖鑑收錄不代表技能已經完成。

## 快速操作

測試模式在控制台提供階段快捷操作，避免每次都等待計時器：

- **夜晚：**「立即結算本夜」
- **警長競選：**「結束警長競選倒數」
- **白天發言：**「跳過目前發言」
- **公投：**「立即結算公投」
- **遺言：**「立即結束遺言」
- **遊戲結束：**「重新開始測試局」

快速操作會呼叫原本的遊戲流程函式，不會直接把當前階段隨意改成任意階段。投票仍需要切換視角，選擇目標並確認投票；夜間操作也需要先從角色控制台提交。

## 建議巡檢順序

1. **基本流程：** 開局發牌 → 夜間行動 → 天亮 → 發言 → 公投 → 遺言 → 下一夜。
2. **主要夜間角色：** 小狼、預言家、女巫、守衛、平民。
3. **其他狼人角色：** 確認共通狼隊夜刀能否顯示，並檢查專屬技能狀態提示。
4. **神職、第三方與特殊角色：** 逐一替換角色，查看各階段面板與狀態提示。沒有專屬控制項的角色應視為待實作，不要當作已完成。
5. **自爆：** 把目前座位替換為小狼，在白天任一允許的階段測試自爆是否中止當前流程並立即入夜。
6. **勝負與重開：** 測試狼人全滅、好人分組出局、平票、無有效票及遊戲結束後重新開始。

## 測試模式範圍與限制

- 視角切換與角色覆蓋僅用於本機測試，不應作為正式多人遊戲的權限模型。
- 測試用角色覆蓋會直接改變該座位的實際角色，供控制項和引擎驗證使用；請勿拿此模式測試真實對局的公平性。
- 尚未接入遊戲引擎的角色會顯示明確的待實作提示；需要逐個補上技能規則、回合觸發點和自動化測試。
- 多人房間同步、伺服器身分驗證與 WebRTC 仍屬後續開發階段。
